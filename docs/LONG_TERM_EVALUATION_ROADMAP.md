# 臨床心理師考題 Agent：企業式長期優化路線圖
更新：2026-10-18 ｜研究來源：[`ML_AGENT_RESEARCH_100_SOURCES.md`](ML_AGENT_RESEARCH_100_SOURCES.md)（100 項不同 URL）。
此文件將企業 ML/AgentOps、專業考題編製與心理計量分開，不把 ChatGPT Agent prompt 改進誤稱底層模型訓練。

## 核心目標：可靠、可追溯、可重現地產生臨床心理師國考模擬題
成功不是「每小時讓單一數字愈來愈高」，而是五層門檻一起成立。

| 軌道 | 指標 | 驗收門檻 | 資料與證據 |
|---|---|---|---|
| A. 程式回歸 | 固定規則、schema、歷屆視窗、題數與版本測試 | 無既有功能退步，重大檢查100%通過 | pytest、log、Git commit |
| B. Agent任務 | 在預設任務集完成所有要求的比例 | 先建立 baseline，再以90%作為長期任務成功率目標 | 20–50典型任務起始、重複trials、trace |
| C. 專業試題 | 獨立領域專家判定完整合格的全新試題比例 | 至少100新題驗收；點估計>=90%，**零關鍵錯誤**；另報95%信賴區間 | 與優化隔離的私有封存題本、專家盲審與分歧仲裁 |
| D. 心理計量 | 難度、鑑別度、誘答選項功能、信度、甲乙平行卷表現 | 有實際考生作答資料後訂可檢驗的閾值；無資料就不得宣稱通過 | 去識別化考生作答、適切統計與樣本數 |
| E. 運維風險 | 工具成功、來源有效、trace完整、花費、延遲、回退 | 無未授權的付費訓練或正式版本覆寫；留存追蹤 | GitHub Actions/實驗log/授權紀錄 |

**重大錯誤例**：診斷或藥理內容錯誤、存在兩個最佳答案、引用虛構來源、來源無法支持解析、錯誤標示正式核可。
**統計注意**：在100題中90題合格，雖達90%點估計，95%信賴區間下界仍低於90%；因此必須另報不確定性，不要把單一次90/100視為已達可泛化的可靠性證據。

## 資料治理
1. 「最新五個考試年度」是**新模擬考卷的歷屆考點選材視窗**，不是保證可當全新模型盲測資料。
2. 現有111–114年歷屆考點供開發／交叉驗證；115年只作**歷史診斷**，因過去版本已使用過，不得標成真正未洩漏測試集。
3. 在訓練／開發資料內再分 validation 或用 group/time cross-validation；同一題、同一命題衍生改寫、甲乙配對、同一考點密集變體必須留在相同分區。
4. 真正保留測試：由未參與開發的專家用新題與保密答案封存於公開 repo 之外；凍結候選版與評分rubric後才進行一次正式驗收。
5. 若驗收失敗，開發迴圈只使用開發資料；新一輪正式驗收應使用重新封存的資料。防止多次看測試錯題造成過度擬合。
6. 正式輸出前的每題資料：來源ID/原文片段或支持位置、版本、難度、認知層次、正解、逐項解析、盲審結果、是否有重大錯誤。

## 改進優先序
P0 基礎設施：GitHub runner 啟動成功、pytest可重現、資料版本與prompt hash、歷屆來源完整性。
P1 命題可靠性：短指令任務自動測試、20題預設與N題可變藍圖、甲乙配對與診斷/藥理來源驗證、Word匯出真實完成測試。
P2 可量化評估：固定開發集、traces、code-based graders；模型裁判只作次級評估且用專家校準。
P3 題目品質：獨立雙人/仲裁審查、醫學教育證據指標，至少100筆封存評測。
P4 心理計量：真實考生資料、題目鑑別度、難度、誘答選項、試卷等值性與信度。
P5 維運與規模：每小時成本與錯誤監控、依變更觸發評測、PR 審查、版本回退與新領域擴充。

## 每小時排程的合理工作（不等同持續訓練）
每輪只做一個受限的改善循環：「查最近變更/問題 → 開發集或靜態檢查 → 變更一項低風險候選 → 回歸比較 → 留紀錄」。若無新證據/變更，略過耗資源的生成，只回報監控結果。
* 禁止每小時啟用固定封存盲測題反覆調參。
* 不設計自動無限回圈、不啟動未授權付費API訓練、不直接更改正式formal-v1.0。
* 若 GitHub Actions 無 runner，報告 blocked；GitHub connector 可讀寫文件不代表擁有可用的測試 runner。
* 完成一次獨立正式驗收達標後，停止朝同一封存集過度擬合，轉以回歸與漂移監控為主。

## 三階段里程碑（按先後依賴，不保證時間）
1. **基礎可執行**：runner穩定、pytest通過、逐次紀錄、端對端10個典型命題/輸出流程驗證。
2. **證據式改善**：至少20–50真實任務案例與例外情境，固定開發測試，作A/B版本比較、保留trace和成本，監控回歸。
3. **嚴格驗收與部署**：獨立專家封存至少100新題、雙人/仲裁，報告合格率與信賴區間；取得作答資料後再開心理計量階段。
