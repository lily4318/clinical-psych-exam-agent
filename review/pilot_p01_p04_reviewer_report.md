# P01–P04 Reviewer Report

Status: reviewer pass completed; user approval pending.

## Review dimensions

- 國考語感與題幹清晰度
- 單一最佳答案
- 干擾選項同層次與鑑別度
- 甲乙卷學習目標、難度、認知層次等值
- 題幹與選項是否有不必要作答線索
- 解析是否能說明正解與各干擾選項
- 歷屆考點與權威來源是否足以支持命題

## P01｜SUD 診斷準則核心概念

結論：通過 reviewer pass。

調整：將四個選項統一為「診斷架構／準則變更」層次，避免正確選項資訊量明顯高於干擾選項。甲卷測現行門檻；乙卷測 DSM-IV 至 DSM-5 核心變更，均維持基礎／記憶。

## P02｜獎賞系統與多巴胺

結論：修正後通過 reviewer pass。

主要問題：舊版甲卷測 mesolimbic reward pathway，乙卷測反覆使用後 neuroadaptation，雖同屬生理心理機制，但不是完全相同學習目標。

修正：甲卷改為辨識 VTA→nucleus accumbens 的 mesolimbic dopamine pathway；乙卷改為辨識 nucleus accumbens 作為該路徑的重要投射目標。兩題皆為基礎／記憶，且不只是同義改寫。

## P03｜TLFB／物質使用量與頻率評估

結論：通過 reviewer pass，作為目前最成熟的應用題模板。

優點：題幹先定義實際評估需求，再要求選擇工具；干擾選項分別代表篩檢、戒斷／生物檢測或其他測量目的，能測出是否理解 TLFB 的功能，而非只記名稱。

## P04｜高風險情境辨識與因應

結論：修正後通過 reviewer pass。

主要問題：v0.1 的錯誤選項過度荒謬，容易靠常識排除，鑑別度不足。

修正：改成數個「部分合理但不完整」的臨床策略，例如只做衛教、只做認知重建、全面迴避或只用單一放鬆技巧，使考生必須辨識 CBT/RP 強調的功能分析＋具體因應技能。

## Overall decision

P01–P04 v0.2 可作為 P05–P20 的命題品質基準，但仍維持 `待複核`，不可視為使用者已核可版本。
